# Jonata Moraes · Portfólio
Portfólio em Dados e QA/Testes, preparado para GitHub Pages.

**Endereço previsto após a configuração e publicação:** https://jonatamoraes97.github.io/

## Conteúdo
- Site estático em HTML, CSS e JavaScript.
- Logo jm_ e contatos por ícones.
- Projetos públicos consultados pela API do GitHub.
- Documentação, arquivos de código, imagens e demonstração do OdontoGestão dentro do portfólio.
- Cópia de conteúdos selecionados para uso quando a API não responder.

Os projetos Python são apresentados com suas evidências e documentação. Eles não são executados pelo GitHub Pages. A demonstração do OdontoGestão continua hospedada no endereço original e é incorporada ao portfólio.

## Publicação
1. Crie o repositório público jonatamoraes97.github.io na conta jonatamoraes97, com um README inicial.
2. Envie o conteúdo desta pasta para a raiz da branch main, com index.html e assets/ no mesmo nível.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
4. Aguarde o fluxo de publicação e confira o endereço exibido na página de configurações.

Não é necessário instalar dependências ou gerar um build. O arquivo .nojekyll preserva os arquivos estáticos.

## Manutenção
- index.html: apresentação e contatos.
- assets/styles.css: aparência.
- assets/data.js: resumos, imagens e cópias dos conteúdos.
- assets/app.js: catálogo, pesquisa e integração com o GitHub.
- assets/logo.svg: logo.

O repositório de hospedagem fica fora do catálogo de projetos. Novos projetos públicos são consultados automaticamente; imagens, resumos personalizados e cópias locais são mantidos em data.js.
